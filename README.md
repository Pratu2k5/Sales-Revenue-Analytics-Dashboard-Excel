# 📊 Sales & Revenue Analytics Dashboard

## 📌 Project Overview
The Sales & Revenue Analytics Dashboard is an interactive Microsoft Excel dashboard created to analyze sales performance and generate meaningful business insights from sales data.
The dashboard provides a clear view of revenue, profit, orders, quantity, products, categories, cities, and monthly sales performance.

## 🎯 Project Objectives
- Analyze overall sales performance
- Track important business KPIs
- Identify top-performing products
- Compare sales across different cities
- Analyze category-wise sales and profit
- Monitor monthly revenue trends
- Present data through an interactive dashboard

## 📊 Key KPIs
- Total Revenue: ₹5.5M
- Total Profit: ₹770.0K
- Total Quantity: 47
- Total Orders: 200
- Average Order Value: ₹27.5K

## 🔍 Dashboard Insights
- Electronics is one of the strongest-performing categories.
- Nashik shows the highest city-wise sales contribution.
- Smartphone is the top-performing product.
- March records the highest monthly revenue in the displayed period.
- Category and city analysis helps identify sales performance differences.
